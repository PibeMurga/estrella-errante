# Prototipo 3D (base visual aprobada el 25/11/2026)

Prueba descartable en Three.js que Lucas aprobó como base visual del juego: cámara inclinada a 35°, sol con granulación, manchas, protuberancias y corona cálida, y planetas en alta definición (oceánico con nubes, luna con cráteres, lava, hielo y gaseoso), sin halos y sin líneas de órbita.

Los shaders de `main.js` son el punto de partida del render del hito 0.

Para verlo: `npx vite docs/diseno/prototipo-3d --port 5180` y abrir `http://localhost:5180/?tilt=35`. Con `&close` se ve el plano cercano.
